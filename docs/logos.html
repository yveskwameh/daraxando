Five directions, each shown as the full logo on dark and on cream, as an app icon at the sizes people will actually see, and sitting on a phone home screen. All of them use Gabarito and the Owambe Night colours.

About the & in the name

Web addresses and social handles can't contain "&", so no domain with the symbol will ever be available. Big brands handle it the same way: H&M uses hm.com, AT&T uses att.com, Marks & Spencer uses marksandspencer.com. So the logo, app name and everything players see say Dara X&O, and the web address and handles spell it out: daraxando. Most of these logos read fine either way.

1 · Drum & Calabash

The X is a talking drum and the O is a calabash seen from above, the two default pieces in the game. On the icon they sit on a diagonal with the &, so the logo is also three in a row. Nobody else can own this, and it reads as X and O even at tab size.
